## 一、框架层服务（自动启动）

以下服务由 `bootstrap.lua` 自动创建，无需手动管理。

### 1.1 bootstrap — 启动引导

| 项目 | 说明 |
|------|------|
| 文件 | `service/bootstrap.lua` |
| 启动 | `skynet_start()` → `bootstrap(logger, "snlua bootstrap")` |
| 职责 | 读取 config，依次启动 launcher / cmaster / cslave / datacenterd / service_mgr / main |

---

### 1.2 launcher — 服务启动器

| 项目 | 说明 |
|------|------|
| 文件 | `service/launcher.lua` |
| 名字 | `.launcher` |
| 职责 | 管理所有 snlua 服务的生命周期（创建/销毁/统计） |

**命令：**

| 命令 | 说明 |
|------|------|
| `LAUNCH service_name ...` | 启动新的 Lua 服务 |
| `LOGLAUNCH service_name ...` | 启动服务并开启日志记录 |
| `LIST` | 列出所有已管理的服务 |
| `STAT addr` | 获取服务状态（消息数、CPU 等） |
| `KILL handle` | 杀掉指定服务 |
| `MEM addr` | 获取内存使用 |
| `GC addr` | 强制 GC 并获取内存 |

> 注意：只追踪 `snlua` 托管的 Lua 服务，C 服务（如 harbor）不在列表中。

## 二、C 服务（系统级）

### 2.1 snlua — Lua 服务宿主 ★★★

| 项目 | 说明 |
|------|------|
| 文件 | `service-src/service_snlua.c` |
| 职责 | Skynet 中**唯一能运行 Lua 代码的 C 服务**，所有 Lua 服务都由它托管 |

`snlua` 不是业务服务，它是"Lua 服务的容器"。类比 Docker 之于容器应用，snlua 之于 Lua 服务。

#### 核心数据结构

```c
struct snlua {
    lua_State * L;           // ★ 独立的 Lua 虚拟机
    struct skynet_context * ctx;  // 对应的 skynet_context
    size_t mem;              // 当前内存使用量
    size_t mem_report;       // 内存告警阈值（初始 32MB，触发后翻倍）
    size_t mem_limit;        // 内存上限（0 = 不限制）
    lua_State * activeL;     // 当前活跃的协程（signal 中断用）
    ATOM_INT trap;           // signal 陷阱标志（0=无，1=设置中，-1=已设置）
};
```

**每个 Lua 服务 = 1 个 `snlua` 实例 = 1 个独立的 `lua_State`。** 服务之间完全隔离。

#### 生命周期

```
snlua_create()  →  snlua_init(args)  →  运行时 dispatch   →  snlua_release()
   创建 VM          加载 Lua 脚本          C→Lua 消息桥          销毁 VM
```

**阶段一：`snlua_create()` — 创建 Lua VM**

```c
snlua_create() {
    l->mem_report = 32MB;
    l->L = lua_newstate(lalloc, l, seed);  // 带自定义内存分配器
}
```

**阶段二：`snlua_init()` — 两阶段启动**

```c
snlua_init(l, ctx, args) {
    skynet_callback(ctx, l, launch_cb);    // 先注册 launch_cb
    skynet_send(ctx, 0, self_handle, ...);  // 自己给自己发一条消息
}
```

> 为什么自己发给自己？`snlua_init` 时线程池还没启动，不能执行 Lua。发消息入队，等 Worker 取出时再安全调用 `launch_cb`。

**阶段三：`launch_cb()` → `init_cb()` — 加载 Lua**

| 步骤 | 操作 |
|------|------|
| 1 | 先清空 `cb`（`skynet_callback(ctx, NULL, NULL)`），禁收外来消息 |
| 2 | `luaL_openlibs(L)` 加载标准库 |
| 3 | 替换 `coroutine.resume/wrap` → profile 版本（记录 CPU 耗时） |
| 4 | 设置 `LUA_PATH` / `LUA_CPATH` / `LUA_SERVICE` 等环境变量 |
| 5 | 加载 `lualib/loader.lua`，传入 args（如 `"myservice"`） |
| 6 | loader 搜索并执行对应的 Lua 文件 |
| 7 | 检查 `memlimit`（Lua 可设置内存上限） |

**阶段四：运行时 — C → Lua 消息桥**

Lua 脚本执行 `skynet.start()` → `c.callback(skynet.dispatch_message)` → 最终 `ctx->cb = _cb`，后续所有消息走 `_cb → lua_pcall → Lua dispatch`。

**阶段五：`snlua_release()`**

```c
lua_close(l->L);     // 销毁 Lua VM
skynet_free(l);      // 释放 snlua
```

#### 关键功能

**1. 内存追踪和限制**

```c
lalloc(ud, ptr, osize, nsize) {
    l->mem += nsize;                 // 追踪总内存
    if (l->mem_limit && l->mem > l->mem_limit) return NULL;  // 超限 → Lua OOM
    if (l->mem > l->mem_report) { l->mem_report *= 2; 告警; }
}
```

Lua 服务可设置内存上限：

```lua
skynet.memlimit(100 * 1024 * 1024)  -- 限制 100MB
```

**2. Signal 中断机制**

- `signal 0`：在 `activeL` 上设 `lua_sethook`，执行 1 条指令后抛 `luaL_error("signal 0")`
- `signal 1`：打印当前内存

`debug_console` 的 `signal :0100000a 0` 命令可随时中断一个"卡住"的协程。

`trap` 字段用 CAS 保证只有一个线程能设置中断：

```
trap=0 → CAS(0,1) → lua_sethook → CAS(1,-1) → signal_hook 被触发
```

**3. Coroutine Profile**

替换协程函数注入计时——记录每个协程的 CPU 耗时，`STAT` 命令可查询 `cpu_cost`：

```c
timing_resume(L, co, n) {
    start = get_time();
    r = auxresume(L, co, n);   // 实际执行
    total_time += diff_time(start);
}
```

#### 与其他模块的关系

```
dispatch_message → ctx->cb = _cb → lua_pcall → Lua service (独立 VM)
                                                   ↑
                                              snlua 托管
                                              - 创建 VM
                                              - 追踪内存
                                              - 替换协程
                                              - 中断支持
```

## 九、编写新的 Lua 服务

### 9.1 最小模板

创建 `examples/myservice.lua`：

```lua
local skynet = require "skynet"

-- 定义命令处理表
local CMD = {}

function CMD.hello(name)
    skynet.error("Hello, " .. name)
    return "Hi, " .. name
end

function CMD.add(a, b)
    return a + b
end

-- 注册 "lua" 协议的处理器
skynet.start(function()
    skynet.dispatch("lua", function(session, source, cmd, ...)
        -- cmd    = 第一个参数（命令名）
        -- ...    = 剩余参数
        -- session= RPC 会话 ID
        -- source = 发送方 handle
        local f = CMD[cmd]
        if f then
            -- skynet.ret 打包并返回结果给调用方
            skynet.ret(skynet.pack(f(...)))
        else
            skynet.error("Unknown command: " .. cmd)
        end
    end)
end)
```

### 9.2 消息通信 API

```lua
-- 发送（不需要回复）
skynet.send(addr, "lua", "hello", "World")

-- 调用（等待回复，协程挂起）
local result = skynet.call(addr, "lua", "add", 1, 2)

-- 按名字查找服务
local addr = skynet.queryservice("SIMPLEDB")
local addr2 = skynet.localname(".launcher")

-- 返回调用结果（在 dispatch 回调中）
skynet.ret(skynet.pack("result"))
```

### 9.3 创建新服务的三种方式

| 方式 | 调用 | 说明 |
|------|------|------|
| **普通创建** | `skynet.newservice("myservice")` | 每次调用创建新实例 |
| **唯一服务** | `skynet.uniqueservice("myservice")` | 已存在则返回已有实例，全局唯一 |
| **按名查找** | `skynet.queryservice("SIMPLEDB")` | 查找全局名对应的 handle（不创建） |

### 9.4 启动新服务

**方式一：在 main.lua 中启动**

```lua
-- examples/main.lua
skynet.start(function()
    -- ... 其他服务 ...
    skynet.newservice("myservice")
end)
```

**方式二：通过 debug_console 动态启动**

```
nc 127.0.0.1 8000
start myservice
```

**方式三：代码中按需启动**

```lua
local addr = skynet.newservice("myservice")
skynet.call(addr, "lua", "hello", "World")
```

### 9.5 响应式服务（处理其他服务发来的请求）

```lua
-- examples/calculator.lua
local skynet = require "skynet"

local CMD = {}
local total = 0

function CMD.add(n)
    total = total + n
    return total
end

function CMD.sub(n)
    total = total - n
    return total
end

function CMD.reset()
    total = 0
end

skynet.start(function()
    skynet.dispatch("lua", function(session, source, cmd, ...)
        local f = assert(CMD[cmd])
        skynet.ret(skynet.pack(f(...)))
    end)
end)
```

使用：

```lua
local calc = skynet.newservice("calculator")
print(skynet.call(calc, "lua", "add", 10))   -- 10
print(skynet.call(calc, "lua", "add", 5))    -- 15
print(skynet.call(calc, "lua", "sub", 3))    -- 12
```

### 9.7 Socket 服务（直接处理 TCP 连接）

```lua
-- examples/echoserver.lua
local skynet = require "skynet"
local socket = require "skynet.socket"

skynet.start(function()
    local listen_fd = socket.listen("0.0.0.0", 9999)
    socket.start(listen_fd, function(fd, addr)
        skynet.error("New client: " .. addr)
        socket.start(fd)  -- 开始接收该客户端的数据

        -- 处理这个客户端的所有消息
        skynet.fork(function()
            while true do
                local msg = socket.read(fd)
                if msg then
                    socket.write(fd, "echo: " .. msg .. "\n")
                else
                    socket.close(fd)
                    skynet.exit()
                end
            end
        end)
    end)
end)
```

### 9.9 完整示例：计数器服务

```lua
-- examples/counter.lua
local skynet = require "skynet"

local count = 0

skynet.start(function()
    skynet.register("COUNTER")

    skynet.dispatch("lua", function(session, source, cmd, ...)
        if cmd == "inc" then
            count = count + 1
            skynet.ret(skynet.pack(count))
        elseif cmd == "get" then
            skynet.ret(skynet.pack(count))
        elseif cmd == "reset" then
            count = 0
        else
            skynet.error("Unknown: " .. cmd)
        end
    end)
end)
```

测试：

```bash
# 通过 debug_console
nc 127.0.0.1 8000
start counter
call COUNTER inc
call COUNTER get
```

### 9.10 文件放置规则

| 文件位置 | 说明 |
|----------|------|
| `service/xxx.lua` | 框架级服务（被 `luaservice` 路径覆盖） |
| `examples/xxx.lua` | 示例/业务服务（被 `luaservice` 路径覆盖） |
| `test/xxx.lua` | 测试服务（被 `luaservice` 路径覆盖） |

`luaservice` 路径在 `config.path` 中定义，`skynet.newservice("xxx")` 会按此路径搜索 `xxx.lua`。如果你的文件放在其他地方，需要加到 `luaservice` 路径中。

## 十、编写 C 服务

### 10.1 三步模板

```c
// service-src/service_mysvc.c
#include "skynet.h"

// ① 自定义结构体（可选）
struct mysvc {
    struct skynet_context *ctx;
    int data;
};

// ② 消息回调
static int
mysvc_cb(struct skynet_context *ctx, void *ud, int type,
         int session, uint32_t source, const void *msg, size_t sz) {
    struct mysvc *m = ud;
    switch (type) {
    case PTYPE_TEXT:
        skynet_error(ctx, "Received: %s", (const char *)msg);
        break;
    }
    return 0;
}

// ③ 三个必须函数
struct mysvc * mysvc_create(void) {
    return skynet_malloc(sizeof(struct mysvc));
}

int mysvc_init(struct mysvc *m, struct skynet_context *ctx, const char *parm) {
    m->ctx = ctx;
    skynet_callback(ctx, m, mysvc_cb);  // ★ 注册回调
    return 0;
}

void mysvc_release(struct mysvc *m) {
    skynet_free(m);
}
```

### 10.2 编译和配置

把 `.c` 文件名加到 `Makefile` 的 `CSERVICE` 列表中：

```makefile
CSERVICE = snlua logger gate harbor mysvc
```

`make linux` 后会生成 `cservice/mysvc.so`，用 `skynet_context_new("mysvc", "param")` 就能启动。但 Lua 层通常不直接创建 C 服务，而是通过 `snlua` 间接管理。C 服务主要用于框架底层（harbor、gate、logger）。
